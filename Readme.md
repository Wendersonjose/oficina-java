# Sistema de Oficina (Java)

Sistema de gestão de oficina desenvolvido em Java com foco em Programação Orientada a Objetos (POO).  
O projeto tem como objetivo aplicar conceitos de modelagem de domínio, encapsulamento e organização em camadas.

---

## 🚀 Tecnologias utilizadas

- Java 17

---

## 📌 Funcionalidades atuais

- Cadastro de Cliente
- Cadastro de Veículo
- Cadastro de Peça
- Cadastro de Serviço

---

## 🧠 Conceitos aplicados

- Encapsulamento
- Composição de objetos
- Organização em pacotes (modelos e serviços)
- Validação básica de dados
- Uso de construtores para garantir consistência dos objetos

---

## ⚠️ Status do projeto

Em desenvolvimento.

---

## 📈 Próximos passos

- Implementação da classe OrdemServico
- Associação de múltiplas peças e serviços
- Cálculo do valor total da ordem
- Evolução para API REST com Spring Boot

---

## 🎯 Objetivo do projeto

Consolidar conhecimentos em desenvolvimento backend com Java, evoluindo de modelagem básica para um sistema com regras de negócio aplicadas.
